Конвертер азбуки Морзе.
Реализовано:
1) HTTP-сервер.
2) Парсинг формы HTML.
3) Создание и регистрировация хендлеров в маршрутизаторе.
4) Выгрузка файлов из HTML-формы.
5) Автоматическое определение содержимого файла (текст или код Морзе).
6) Использован готовый методод, который позволяет конвертировать текст в код Морзе или наоборот.

Проект состоит из трёх пакетов, не считая основного:
1) Пакет server. Функция, которая создаёт новый сервер, http-роутер и регестрирует ваши хендлеры в нём.
2) Пакет service. Функция, которая автоматически определяет, в каком виде (текст или код Морзе) получены данные из файла.
3) Пакет handlers. В пакете handlers создаданы два хендлера:
  первый для отправки файла с формой HTML index.html;
  второй для загрузки файла с данными из этой формы.

В корне проекта находятся два тестовых файла test и test12: в первом файле код Морзе, во втором — простой текст.
